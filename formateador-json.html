Formateador JSON

Pega JSON desordenado y lo indenta correctamente. Nada se envía a ningún servidor.

¿Para qué sirve un formateador JSON?

Cuando una API devuelve una respuesta en una sola línea, sin espacios ni saltos, es casi imposible leerla a simple vista. Esta herramienta la reorganiza con la indentación correcta para que puedas revisar la estructura, encontrar un campo concreto o detectar un error de sintaxis rápidamente.

¿Es seguro pegar datos aquí?

Sí: el procesamiento ocurre por completo en tu navegador con JavaScript. El texto que pegas nunca se envía a ningún servidor, así que puedes usarlo incluso con datos sensibles de tus propios proyectos.
