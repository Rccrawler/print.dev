Intérprete de Python

Ejecuta Python real en tu navegador. El código se procesa localmente y nada se envía a un servidor.

La primera ejecución carga Python en el navegador y puede tardar unos segundos.

¿Cómo funciona?

Esta herramienta usa Pyodide para ejecutar CPython compilado a WebAssembly dentro del navegador. La primera ejecución descarga el runtime; después se reutiliza mientras la página siga abierta y el navegador puede conservarlo en caché.

¿Qué puedo probar?

Puedes usar sintaxis real de Python, listas, diccionarios, funciones, excepciones y muchas partes de la biblioteca estándar. Las librerías externas pueden necesitar una carga adicional.
