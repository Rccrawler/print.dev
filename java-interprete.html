Mini intérprete de Java

Un subconjunto básico de Java — variables, System.out.println, if/else, for, while — ejecutado por completo en tu navegador.

Solo lo básico: sin clases, métodos propios, arrays ni imports.

¿Cómo funciona sin instalar el JDK?

Este intérprete no usa Java real por debajo: es un tokenizer, un parser y un evaluador escritos desde cero en JavaScript que entienden un subconjunto del lenguaje. Analiza tu código, lo convierte en una estructura interna y la ejecuta paso a paso, tal y como haría un intérprete de verdad, pero a menor escala.

¿Qué puedo probar aquí?

Declaraciones de variables (int, double, boolean, String), impresión por consola, operadores aritméticos y lógicos, condicionales if/else, y bucles for y while. Es ideal para probar un fragmento rápido sin abrir un IDE.
